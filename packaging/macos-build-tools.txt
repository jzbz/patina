# meson, ninja and cmake for packaging/macos-libmpv-build.sh, which
# installs them into a virtual environment of their own with
#   pip install --require-hashes --only-binary :all: --no-deps -r <this file>
# so pip takes nothing but these three wheels, each with the digest below.
# None of them has dependencies of its own. ninja and cmake are universal2
# wheels with the binaries inside; meson is pure Python and needs Python
# 3.10 or later, which the script checks for first.
#
# To bump one, take the version and the digest of the wheel macOS uses
# (`py3-none-any` for meson, `macosx_*_universal2` for the others) from
#   curl -fsSL https://pypi.org/pypi/<name>/<version>/json | python3 -c 'import json, sys; [print(u["filename"], u["digests"]["sha256"]) for u in json.load(sys.stdin)["urls"]]'
# and check that mpv and libplacebo still build with it. mpv 0.42.0 and
# libplacebo 7.387.0 need meson 1.3.0 or later; libwebp needs cmake 3.16,
# and uchardet's CMakeLists.txt is older than cmake 4 accepts without
# CMAKE_POLICY_VERSION_MINIMUM, which the script passes.
